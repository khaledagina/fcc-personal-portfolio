# Khaled Agina | Portfolio

Personal portfolio for Khaled Agina: front-end developer and AI student at Delta University for Science and Technology.

This is a **freeCodeCamp Responsive Web Design certification project**, redesigned. The original submission followed freeCodeCamp's required user stories. This version keeps those requirements (ids, structure, semantics) and rebuilds the visual design, content and interactions.

**Live demo:** https://khaledagina.github.io/fcc-personal-portfolio/

## Preview

![Khaled Agina portfolio, desktop view](https://github.com/user-attachments/assets/5b53be45-6ff5-4951-9608-71d111e9d3d2)

## What changed in the redesign
- Real name, role, links and projects (the original used sample placeholder text)
- Project tiles linking to live demos and source code
- Active section tracking in the navigation and scroll reveal animations

## Built with
- HTML5 and semantic elements
- CSS3 (custom properties, Flexbox, Grid, media queries)
- A small amount of vanilla JavaScript
- Responsive from 320px up, keyboard focus styles, `prefers-reduced-motion` support

## Run locally
Open `index.html` in a browser. No build step.
